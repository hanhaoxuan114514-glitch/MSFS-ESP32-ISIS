# 验证状态

## 已验证

- 指定无触摸板卡正常显示，180° 方向和断电重连正常。
- USB 发送真实 SimConnect 数据，设备确认收到姿态、空速、高度、杆位、反推、油量和垂直速率。
- 单发与双发飞机数据接收正常；设备日志观察到反推展开值随操作恢复为零。
- Windows 助手能够启动和停止桥接、进入托盘，并核对原有桥接进程身份。
- 当前固件已烧录并通过写入哈希校验。最新布局为左百分比＋右粗油门条，FUEL 与 V/S 统一 28 号白色字体。
- 19 项 Python 测试通过；桌面进程身份测试通过。

## 尚待完成的验收

- 实际四发飞机在硬件上的四路显示。四发→双发的数据切换和无效数量处理已有测试。
- 所有第三方机型的杆位、反推语义与专有 ISIS 数据映射。
- 控制输入下完整的俯仰、横滚方向测试，以及持续动态场景的刷新率测量；不把静态首帧耗时当作持续 FPS。
- 新机器从干净克隆环境构建固件与便携运行包。
- `tests/embedded/` 中的 C/Unity 用例：已编写，尚未作为独立测试固件执行。
