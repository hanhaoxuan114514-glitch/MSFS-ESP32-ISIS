# USB 数据协议 v1

Windows 通过 USB Serial/JTAG 虚拟串口发送 ASCII JSON，每条以换行结束。默认 20 Hz，每行不超过 1024 字节（不含换行）。链路只发送显示数据，不向游戏写入控制事件。

## 状态字段

| 字段 | 约束 |
| --- | --- |
| `version` | `1` |
| `session` | 32 个十六进制字符，会话内不变 |
| `seq` | 无符号 32 位整数，同一会话严格递增，不回绕 |
| `connected` | 布尔值，是否有新鲜真实数据 |
| `demo` | 布尔值；实际桥接输出 `false` |

`connected:true` 还须包含：

| 字段 | 含义与范围 |
| --- | --- |
| `pitch_deg` / `bank_deg` | 俯仰 -90…90° / 横滚 -180…180° |
| `ias_kt` | 指示空速 0…1500 kt |
| `altitude_ft` | 指示高度 -2000…100000 ft |
| `heading_deg` | 磁航向 0…360°，360 规范为 0 |
| `vertical_speed_fpm` | 垂直速度 -30000…30000 ft/min |
| `qnh_hpa` | 气压设定 700…1200 hPa |
| `on_ground` | 是否在地面 |

## 可选字段

- `mach`：0…5。
- `engine_count`：整数 0…4；不存在时固件兼容旧双发协议。
- `throttle1_pct` … `throttle4_pct`：-100…100，负值保留用于反推识别。
- `reverse1_pct` … `reverse4_pct`：反推装置展开百分比 0…100。
- `fuel_pct`：剩余总油量占总容量的比例，0…100。
- `latitude_deg`、`longitude_deg`：保留协议兼容，当前界面不显示。

每路发动机的杆位和反推字段同时存在且有效，设备才将该路标记为可显示。桥接不发送超出实际发动机数量的读数。油门条按杆位绝对值显示，负杆位小于 -0.5% 或反推展开超过 1% 时显示 REV；这不是 N1 或反推推力百分比。

## 示例

以下仅演示协议结构，不是当前游戏读数，也不是供设备播放的模拟数据模式：

```json
{"version":1,"session":"0123456789abcdef0123456789abcdef","seq":7,"connected":false,"demo":false}
```

## 校验与失联

固件拒绝非法类型、非有限数字、越界数据、重复键、超长行和旧序列。只有整帧校验成功后才原子更新快照。无效输入和重复序列不会延长数据有效期。

`connected:false` 立即标记失联；最后有效实时帧超过 1500 ms 同样失联。屏幕以缺失值与姿态标志表达失联，不把旧读数当作当前数据。新会话只在旧会话断开或超时后接管。
